# 雨课堂学习助手 Pro · 使用指南

适用站点：长江雨课堂（`*.yuketang.cn` / `*.gdufemooc.cn` 等同类平台）
脚本文件：`yuketang-helper.user.js`

---

## 一、安装

### 方式 ①：一键刷课（推荐）

**双击项目根目录的 `一键刷课.exe`**——自动完成：检测调试端口→必要时启动带调试的 Edge→
后台启动 watchdog（每次刷新自动补注入）。
然后在弹出的浏览器里登录雨课堂即可——**没登录也没关系，exe 会显示 `waiting for login` 持续等你登录成功**，脚本面板也会显示「⏳ 未登录」提示，登录后自动继续。

> 要求：Windows + Edge/Chrome，免 Python 免安装。watchdog 控制台窗口保持开着。

### 方式 ②：油猴（备选）

1. Edge / Chrome 浏览器安装扩展 **Tampermonkey（篡改猴）**
2. 点浏览器右上角 Tampermonkey 图标 → **添加新脚本**
3. 删除编辑器里的默认内容，把 `yuketang-helper.user.js` **全文**粘贴进去 → `Ctrl+S` 保存
4. 确认脚本列表里它是**已启用**状态

## 二、开始刷课

### 方式 A：课程列表全自动（推荐）

打开 `…/pro/courselist`（先登录）→ 面板出现 → **选课面板自动弹出**：
勾选想刷的课点「打开所选」，或等 30 秒自动开全部未刷——每门一个新标签各自开刷。

### 方式 B：单门课

进入你要刷的那门课的**课程目录页**（能看到一列课时的页面，网址含 `studycontent`）→ 面板点 **▶ 开始**。

### 方式 C：多门课同时刷（本脚本特色）

**最快方式：选课面板自动批量开标签。** 进入课程列表页 `pro/courselist`，
面板会**自动弹出选课界面**：

- 列出全部课程及状态徽标（已完成 / 进行中 / 未刷）
- 默认勾选全部"未刷"课程，可手动改勾
- **30 秒不操作 → 自动尝试打开全部未刷课程**，每门一个新标签、各自自动开刷
- 已关闭后想重开：点标题栏 **📚** 图标（仅课程列表页可用）
- 面板打开期间，本标签不会自动选课跳走（暂停 45 秒）

> 弹窗拦截提示：点「打开所选」＝用户手势，放行率高；倒计时自动打开
> 可能被浏览器拦截——此时点地址栏右侧 🚫 图标「始终允许弹窗」后重试，
> 或**逐个点击课程名链接**（点击＝手动，必放行）。

手动方式依然可用：直接多开几个标签页各打开一门课目录页，每个标签等自动启动即可。
脚本互相协调：**同一门课只会有一个标签在刷**，撞车的标签自动让出、回课程列表挑别的课；
某门课刷完后该标签自动回课程列表页，随机挑一门还没刷完/没被占用的课接着刷，**直到全部刷完**。

## 三、面板怎么看

```
┌─ ● 雨课堂学习助手 Pro 运行中 📚选课 🌙主题 ?帮助 ⏻开关 ─┐
│ ┌──────────────────────────────────┐ │
│ │ 科研伦理与学术规范      第 3/7 门 │ │  ← 状态卡：课程名+批量进度
│ │ 视频 ▓▓▓▓▓▓▓▓░░░░░░      33/46  │ │  ← 视频进度条
│ │ 作业 ▓▓░░░░░░░░░░░░       2/8   │ │  ← 作业条（仅作业代答开启时出现）
│ │ 当前第 34 节           ⏱ 01:24  │ │
│ └──────────────────────────────────┘ │
│ 第 3/5 题  答案：选 A·B·D              │  ← 答题助手横幅（仅开启时显示）
│ 运行日志                        [▾]  │
│  · 已接管播放器：video 2x 静音        │
│ [ ▶ 开始 ] [ ⏸ 暂停 ] [ ⏹ 退出批量 ]  │  ← 第三键随状态变（见第八章）
│ ⚠作业代答 ○──        倍速 [ 2x ▼ ]   │
│ [📋答题助手][⚙AI设置][🗑清缓存][↻重载] │
└──────────────────────────────────────┘
```

- 状态灯：🟢 运行中 / 🟡 已暂停 / ⚪ 待机
- **主题切换**：标题栏 `🌙/☀️` 按钮切深浅色，默认浅色（白底），选择自动记住
- **进度条口径**：默认只统计「视频/音频」课时——讨论、作业、考试、图文不计入分母；「正在播第 X 节视频」按媒体序号显示；视频全刷完时进度条变**绿色**拉满、课程名加 ✅、放一次烟花 🎉
- 开启「作业代答」后变成双进度条：视频、作业各算各的
- 面板可拖拽（按住标题栏）、可最小化（`—` 收成小球，点球还原）
- 日志区可折叠（`▾`）

## 四、两种做题模式：作业代答 vs 答题助手

| | ⚠ 作业代答（全自动） | 📋 答题助手（半自动） |
|---|---|---|
| 谁勾选提交 | **脚本自动**勾选并提交 | **你亲自**勾选并提交 |
| 与刷视频 | 混在一起全自动跑 | 独立——开启后刷课暂停推进，只做题 |
| 风险 | 提交不可修改 | 零风险，答案只供对照 |
| 适用 | 信任题库、想完全放手 | 想逐题核对后再提交 |

两者**互斥**（开一个自动关另一个），都只服务两门内置题库课程：**科研伦理与学术规范**、**生物医药实验室安全知识**（题库已按原始答案图逐题核对）。

### ⚠ 作业代答（默认关，想清楚了再开）

**这个功能会自动提交作业答案，提交后不可修改。**

- 开启：拨动「⚠ 作业代答」开关 → 弹窗确认 → 滑块变红
- 行为：遇到这两门课的"作业"课时自动进入，按题号顺序勾选（单选/多选/判断都支持），**全部题都有答案才自动提交**；有任何一题题库缺失或没识别到 → 整卷留空不提交，日志列出缺哪几题，人工补答后自己点提交
- **其它课程完全不受影响**（作业照旧跳过），**期末考试永远不答**
- 第一次用建议盯着第一个作业的勾选日志确认无误

### 📋 答题助手（半自动，保守推荐）

- 开启：点「📋 答题助手」→ 弹窗说明确认 → 按钮变金色
- 开启后**刷课推进暂停**（不会自动跳下一节）；你手动进入作业课时
- 面板出现**金色答案横幅**：自动识别当前第几题，逐题显示 `第 3/20 题 · 答案：选 A·B·D`（判断题显示 √/×）；点题号标签横幅跟着变
- 照着横幅自己勾选、自己点提交——脚本只读不代点
- 作业页若无题号标签（整卷铺开），横幅列出全部答案序号供对照
- 答完关闭开关，点「▶ 开始」恢复刷课

## 五、倍速选择

「2x 倍速」下拉可自由切：**2x（默认）/ 拟人随机 1.5~2.5x / 1x / 1.5x / 2.5x / 3x 极速**——立即生效并记住选择。追求隐蔽选「拟人随机」。

## 六、刷课过程中的表现（都是正常的）

- 视频以所选倍速 + 静音播放，切后台/切标签页不会停
- 图文课时会自动点开停留约 2 秒完成阅读上报，然后继续下一条（不计入视频进度条分母）
- 讨论帖、考试课时自动跳过（**不替你发帖、不答题**）
- 课时之间有几秒随机停顿（模拟真人）
- 面板实时滚动运行日志

## 七、需要你手动做的唯一一件事

**弹出腾讯滑块验证码时，手动滑一下。**
- 多标签同时刷比单开更容易弹验证码，平台风控无法绕过
- 滑完即自动继续，不用重新点按钮

## 八、暂停 / 停止 / 批量模式

| 按钮 | 行为 |
|---|---|
| ▶ 开始 | 启动 / 从暂停恢复 |
| ⏸ 暂停 | 当前集播完后停下，页面不刷新；点开始原地恢复 |
| 第三个键（随状态变） | **批量中→「⏹ 退出批量」**：清批量进度并停本标签，**不刷新页面**，其他标签不受影响 · **空闲/已暂停→「▶ 进入批量」**：一键回自动选课连播 · **单课运行中→「⏹ 停止」**：停本标签并刷新 |
| ↻ 重载 | 刷新页面并自动恢复刷课 |
| 📚选课（顶部） | 手动挑课开新标签——不打断当前流程，非自动跳转 |
| ⏻开关（顶部） | 脚本总开关（所有标签）：关闭后不弹窗不刷课，再点恢复 |

**批量模式的自动时序**：选课面板关闭后 → **60 秒缓冲倒计时**（顶部状态栏实时显示 `选课 Ns`）→ 期间点 ⏸暂停/⏹退出批量/重开面板都可取消 → 倒计时结束自动挑课进入。

想暂停所有标签：每个标签各点一次「⏸ 暂停」或「⏹ 退出批量」。

## 九、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 面板没出现 | 确认 Tampermonkey 已启用脚本；刷新页面 |
| 提示"课时未解锁" | 课程有开放时间限制，脚本每 30 分钟自动重试，解锁后自动开刷 |
| 卡在验证码 | 手动滑块；滑完不动就刷新页面，脚本自动恢复 |
| 某标签提示"正在其他标签页刷课中" | 正常，那门课已有人在刷，本标签自动去刷别的 |
| 倍速被平台弹回 1x | 脚本每 5 秒自动重申，观察几秒即可 |
| 同一页面出现两个面板 | 新旧版本叠加了，刷新页面即可 |
| 进度条分母比侧边栏课时少 | 正常：只统计视频课时，讨论/作业/考试不计入 |
| 视频刷完但侧边栏还有未完成 | 那些是讨论/作业/考试，本就不计入视频进度 |
| "正在播第 X 节"和侧边栏序号对不上 | 正常：X 是视频课时的序号，讨论/作业不占位 |

## 十、重要提醒

- 视频是**真实播放**（进度靠实际观看上报），相对安全；但"倍速+长时间连续观看"仍有被平台风控识别的可能，**同时刷的课越多特征越明显**。求稳建议一次 2~3 门
- 不要在「AI 设置」里随意开启自动答题/自动评论——默认全关最安全
- 课程考核中讨论、作业若计入总分且未在题库内，需要你自己完成，脚本不代劳也不添乱
