# 雨课堂学习助手 Pro · 使用指南

适用站点：长江雨课堂（`*.yuketang.cn` / `*.gdufemooc.cn` 等同类平台）
脚本文件：`yuketang-helper.user.js`

---

## 一、安装（一次性，约 2 分钟）

1. Edge / Chrome 浏览器安装扩展 **Tampermonkey（篡改猴）**
2. 点浏览器右上角 Tampermonkey 图标 → **添加新脚本**
3. 删除编辑器里的默认内容，把 `yuketang-helper.user.js` **全文**粘贴进去 → `Ctrl+S` 保存
4. 确认脚本列表里它是**已启用**状态

## 二、开始刷课

### 方式 A：课程列表全自动（推荐）

打开 `…/pro/courselist`（先登录）→ 左上角深色面板出现 → **约 10 秒自动开始**：随机选一门未完成课程进入开刷，刷完自动接下一门。

### 方式 B：单门课

进入你要刷的那门课的**课程目录页**（能看到一列课时的页面，网址含 `studycontent`）→ 面板点 **▶ 开始**。

### 方式 C：多门课同时刷（本脚本特色）

- 直接**多开几个标签页**，每个标签打开一门课的目录页
- 每个标签各点一次「▶ 开始」（或等自动启动）
- 脚本互相协调：**同一门课只会有一个标签在刷**，撞车的标签自动让出、回课程列表挑别的课
- 某门课刷完后，该标签自动回课程列表页，随机挑一门还没刷完/没被占用的课接着刷，**直到全部刷完**

- 日志区可折叠（`▾`）

## 四、作业代答（默认关，想清楚了再开）

⚠ **这个功能会自动提交作业答案，提交后不可修改。**

- 只对两门内置题库的课程生效：**科研伦理与学术规范**、**生物医药实验室安全知识**（题库已按原始答案图逐题核对）
- 开启：拨动「⚠ 作业代答」开关 → 弹窗确认 → 滑块变红
- 行为：遇到这两门课的"作业"课时自动进入，按题号顺序勾选（单选/多选/判断都支持），**全部题都有答案才自动提交**；有任何一题题库缺失或没识别到 → 整卷留空不提交，日志会列出缺哪几题，你人工补答后自己点提交
- **其它课程完全不受影响**（作业照旧跳过），**期末考试永远不答**
- 第一次用建议盯着第一个作业的勾选日志确认无误

## 五、倍速选择

「2x 倍速」下拉可自由切：**2x（默认）/ 拟人随机 1.5~2.5x / 1x / 1.5x / 2.5x / 3x 极速**——立即生效并记住选择。追求隐蔽选「拟人随机」。

## 六、刷课过程中的表现（都是正常的）

- 视频以所选倍速 + 静音播放，切后台/切标签页不会停
- 讨论帖、考试课时自动跳过（**不替你发帖、不答题**）
- 课时之间有几秒随机停顿（模拟真人）
- 面板实时滚动运行日志

## 七、需要你手动做的唯一一件事

**弹出腾讯滑块验证码时，手动滑一下。**
- 多标签同时刷比单开更容易弹验证码，平台风控无法绕过
- 滑完即自动继续，不用重新点按钮

## 八、暂停 / 停止 / 恢复

| 按钮 | 行为 |
|---|---|
| ▶ 开始 | 启动 / 从暂停恢复 |
| ⏸ 暂停 | 当前集播完后停下，页面不刷新；点开始原地恢复 |
| ⏹ 停止 | 彻底停止并刷新页面（批量状态清空） |
| ↻ 重载 | 刷新页面并自动恢复刷课 |

想暂停所有标签：每个标签各点一次「⏸ 暂停」或「⏹ 停止」。

## 九、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 面板没出现 | 确认 Tampermonkey 已启用脚本；刷新页面 |
| 提示"课时未解锁" | 课程有开放时间限制，脚本每 30 分钟自动重试，解锁后自动开刷 |
| 卡在验证码 | 手动滑块；滑完不动就刷新页面，脚本自动恢复 |
| 某标签提示"正在其他标签页刷课中" | 正常，那门课已有人在刷，本标签自动去刷别的 |
| 倍速被平台弹回 1x | 脚本每 5 秒自动重申，观察几秒即可 |
| 同一页面出现两个面板 | 新旧版本叠加了，刷新页面即可 |

## 十、重要提醒

- 视频是**真实播放**（进度靠实际观看上报），相对安全；但"倍速+长时间连续观看"仍有被平台风控识别的可能，**同时刷的课越多特征越明显**。求稳建议一次 2~3 门
- 不要在「AI 设置」里随意开启自动答题/自动评论——默认全关最安全
- 课程考核中讨论、作业若计入总分且未在题库内，需要你自己完成，脚本不代劳也不添乱
